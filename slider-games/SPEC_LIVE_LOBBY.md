# МАРБЛС · «Живое лобби» — спецификация плашек комнат (для Godot)

Референс: `Живое лобби.dc.html` → вариант 2a (лента внизу). Компонент: `Лобби экран.dc.html`.
Шрифт на макете — Nunito как ближайший аналог; в Godot использовать шрифт проекта, сохраняя вес (800/900 — жирный) и размеры.
Экран 390×719. Все размеры — px макета.

---

## 0. Что это

На главном экране внизу — лента плашек «кто-то ищет игроков». Плашки появляются, набирают игроков, «заполняются» и уезжают за край — как будто там началась игра. Последние 5 «начавшихся» остаются в архиве (свайп вправо / ссылка «Идут игры»), тап по ним — режим зрителя. Тап по живой плашке — сесть за стол.

Плашки **плоские**: без падающей тени и без утолщённого нижнего края (в отличие от больших кнопок меню).

---

## 1. Бордеры плашки по состояниям

Плашка 300×96, радиус 18. Рамка = `box-shadow: 0 0 0 1.5px <цвет>` (внешняя, не влияет на размер). Других теней нет.

| Состояние | Фон плашки | Рамка 1.5px | Значение |
|---|---|---|---|
| `live` — идёт набор | `#FFF0BE` | `#E7A82B` (золотая) | обычная |
| `full` — все нашлись (1.5 с) | `#FFF0BE` | `#9B6B0B` (тёмно-золотая) | акцент «сейчас стартует» |
| `started` — идёт игра (архив) | `#F7EBC9` | `#D9B25A` (блёклая) | приглушённая, неактивная |
| `gone` — исчезла | — | — | opacity → 0 |

Переход между состояниями: opacity .5s, transform .7s `cubic-bezier(.22,.9,.28,1)`, box-shadow .3s.

Архивные плашки при показе имеют opacity .92.

Рамка аватара внутри плашки: круг 38px, обводка `1.5px rgba(60,35,0,.35)`.

---

## 2. Кружочки заполненности комнаты

Ряд кружков под именем: слева `left:58px`, `top:36px`, высота 16.

- Количество кружков = число мест за столом (`players`, 2–6).
- Размер кружка 15×15, gap 4px, `box-sizing: border-box`.
- Сразу справа текст `«N из M»` (например `2 из 4`): `800 12.5px #5a3d06`, отступ слева 4px.

Состояния кружка:

| Состояние | Фон | Рамка 1.5px | Масштаб |
|---|---|---|---|
| занято | `#F7E25A` | **сплошная** `#E7A82B` | 1 |
| только что сел (≤500 мс) | `#FFF3A8` | сплошная `#E7A82B` | **1.45** (вспышка) |
| свободно | `rgba(255,255,255,.55)` | **штриховая** `#D2A94E` | 1 |

- Анимация кружка: `transform .25s`, `background .25s` — вспышка «пружинит» обратно к 1.
- Заполняются слева направо: k-й кружок занят, если `k < joined`.
- Динамика набора: стартует с 1–2 игроков из N; +1 игрок каждые **1.8–4.2 с** (случайно). Когда `joined == players` → состояние `full`.
- В состояниях `full` и `started` все кружки заняты.
- Текст «N из M» всегда показывает фактическое число (в `full`/`started` — `M из M`).

## 3. Штриховые и сплошные линии

**Штриховые (dashed) — «пусто / граница зоны»:**
- Верхний разделитель нижней полосы плашки: `border-top: 1.5px dashed` — `#E7A82B` (live, full) / `#D9B25A` (started).
- Свободное место (кружок в плашке): `1.5px dashed #D2A94E`.
- Свободное место в шторке: круг 44px, `2px dashed #D2A94E`, подпись «ждём» `#A98B56`.

**Сплошные (solid) — «занято / объект»:**
- Рамка плашки (см. п.1).
- Занятый кружок, занятое место в шторке (`2px solid rgba(60,35,0,.35)`), место «Вы» (`2px solid #9B6B0B`).
- Рамки кнопок «Играть!» / «Смотреть» (`0 0 0 1.5px`).
- Рамка блока-подсказки в шторке: `inset 0 0 0 1.5px #EFD48D`.

Правило: **штрих = ещё нет / свободно / граница секции; сплошная = есть / занято / интерактивный объект.**

## 5. Раскладка и движение

- Меню главного экрана поднято на 128px относительно прежнего положения. Заголовок ленты `top:556`, плашки `top:600` (высота 96, низ 696). Версия `top:702`.
- Лента горизонтальная: шаг 310 (300 + gap 10). Видна одна плашка, следующая «выглядывает» справа.
- Новая плашка въезжает справа. Заполнилась → 1.5 с «Все нашлись» → уезжает **влево** за край и становится архивной.
- Архив: последние 5 (6-я растворяется). Свайп вправо — архив слева от живых; ссылка «Идут игры» делает то же. Через 9 с без касаний лента возвращается к живым.
- Всегда держим 2–3 живые плашки; если меньше — новая появляется через 1–1.8 с.

## 6. Данные и правила

- Мест за столом: 2–6. Ставка: 0 / 25 / 50 / 100 / 500 / 1000.
- Банк = ставка × игроки; комиссия = 10% (округл.); выигрыш = банк − комиссия; **XP = выигрыш − ставка**.
- Время на ход — 5 минут. Цвет шарика игрока назначается случайно (не совпадает с занятыми).
- Тап по `live`: шторка «Сесть за стол». Если игрок последний — сразу старт; иначе «Собираем стол… N из M» ~1.3 с на игрока, затем «Стол собран!» → переход к столу через 2.2 с.
- Тап по `started`: шторка зрителя («Смотреть партию»): видит ходы, не ходит, фантики не получает.
- `full`-плашки не кликабельны.
- Haptic: `Telegram.WebApp.HapticFeedback.impactOccurred('medium')` на тап плашки, ссылки и кнопки шторки.
