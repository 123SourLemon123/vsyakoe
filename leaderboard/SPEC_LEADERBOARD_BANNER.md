# МАРБЛС · Синий баннер «Рейтинг игроков» на главном экране (для Godot)

Референс: `Лидерборд - варианты.dc.html` → вариант **1a** (компонент `Лобби экран.dc.html`, параметр `lb="banner"`).
Иконка: `assets/icons/icon_trophy.svg`. Бриллиант XP: `assets/icons/icon_xp_gem.svg`.
Размеры — px макета 390×719. Шрифт на макете Nunito; в Godot — шрифт проекта с теми же весами.

---

## 1. Что не так в текущей реализации (по скриншоту)

1. Баннер плоский: нет градиента, нет нижнего 3D-края, нет внутреннего блика.
2. Нет белой плитки с кубком слева.
3. Текст в одну строку, разнесён по краям («Рейтинг» слева, подсказка справа). Должно быть **два ряда друг под другом**: заголовок и подпись.
4. Нет внутренних отступов: «Рейтинг» упирается в левый край.
5. Нет блока справа (три аватарки + шеврон «›»).
6. Высота ~44 px вместо **72**. Баннер выглядит как строка текста, а не как кнопка.
7. Баннер прилеплен к «Динамично как в UNO», снизу огромная пустота. Нужно центрировать по вертикали (см. п. 6).
8. Заголовок: должно быть «Рейтинг игроков» (не «Рейтинг»).

## 2. Геометрия

- Ширина **300**, высота **72**, по центру экрана (`left = 45` при ширине 390 — как у кнопок меню, плашки, «Дропов»).
- Скругление **20**.
- Внутренние отступы: слева **12**, справа **14**, сверху/снизу — контент по центру по вертикали.
- Содержимое — одна горизонтальная строка (HBox), `separation = 11`, выравнивание по центру по вертикали:

| # | Блок | Размер | Поведение |
|---|---|---|---|
| 1 | Плитка с кубком | 46×46 | фиксированная |
| 2 | Текстовая колонка (VBox, `separation = 6`) | растягивается | занимает всё свободное место |
| 3 | Аватарки + шеврон | по содержимому | фиксированная, прижата вправо |

## 3. Фон, рамка, объём (главное отличие от плоского)

Это **«синяя копия» главной золотой кнопки**: тот же принцип «лицо + рамка + нижний край».

- **Лицо:** радиальный градиент (эллипс 100% × 150%, центр в точке 30% ширины / верх), стопы:
  `#6AA6FF` (0%) → `#3A7AEA` (50%) → `#2459CC` (100%).
  В Godot — `GradientTexture2D` с `fill = FILL_RADIAL`, `fill_from = (0.3, 0)`, `fill_to = (0.3, 1.0)` (или заготовленный PNG/SVG 300×72 с этим градиентом).
- **Рамка:** внешний контур **2 px** `#1C54BF`.
- **Нижний край (толщина):** на макете `box-shadow: 0 4px 0 2px #153F96` — сплошная тень без размытия, смещённая на 4 px вниз и расширенная на 2 px. В Godot: `StyleBoxFlat` с `shadow_color = #153F96`, `shadow_offset = (0, 4)`, `shadow_size = 0`, либо второй `Panel` того же размера под лицом, смещённый на +4 по Y.
- **Внутренний блик:** верхняя внутренняя подсветка **2 px**, `rgba(255,255,255,.45)` (в Godot — тонкая светлая линия/полоса вдоль верхнего края внутри баннера, повторяет скругление; или `StyleBoxFlat.border_width_top = 2` светлым цветом на отдельном слое).
- **Падающей мягкой тени (blur) нет** — баннер плоский по сравнению с золотыми кнопками. Только нижний край 4 px.
- Золотые кнопки меню имеют край 6 px и размытую тень; у баннера край **4 px** и тени нет — так он визуально «второстепенный».

### Состояние нажатия
При `pressed`: сдвиг баннера на **+2 px вниз**; нижний край, соответственно, становится 2 px (или баннер просто смещается на 2 px). Длительность 0.08 с. Haptic: `Telegram.WebApp.HapticFeedback.impactOccurred('medium')` на тап.

## 4. Содержимое

### 4.1 Плитка с кубком (слева)
- Квадрат **46×46**, радиус **14**.
- Фон: вертикальный градиент `#FFFFFF` (верх) → `#D6E5FF` (низ).
- Рамка: **1.5 px** `rgba(18,58,138,.55)`.
- Внутри по центру `icon_trophy.svg`, **30×30** (цветной, золото `#F2B91E` с тёмным контуром — не перекрашивать).

### 4.2 Текстовая колонка (два ряда, друг под другом)
- **Заголовок:** «Рейтинг игроков» — вес **900**, **16 px**, цвет `#FFFFFF`, одна строка (не переносить), тень текста `0 1px 0 rgba(10,40,110,.35)` (в Godot — `outline`/`shadow` у Label: цвет `#0A286E`, прозрачность ~.35, смещение (0, 1)).
- **Подпись:** вес **700**, **12.5 px**, цвет `#FFFFFF` (полностью белый, **не** прозрачный и не серо-голубой), одна строка, тень `0 1px 0 rgba(10,40,110,.3)`.
- Расстояние между заголовком и подписью: **6 px**.
- Выравнивание текста — **по левому краю**.

### 4.3 Тексты подписи (зависят от состояния игрока)
| Состояние | Подпись |
|---|---|
| есть XP > 0, игрок в рейтинге | «Ваше место · 128» (подставить реальное место) |
| 0 XP, места нет | «Начните играть — получите XP» |

Заголовок «Рейтинг игроков» одинаковый во всех состояниях. Если подпись длиннее доступной ширины — подпись сокращать, а не переносить (приоритет: оставить аватарки и шеврон).

### 4.4 Правый блок: аватарки + шеврон
- Три круглые аватарки **24×24** встык с перекрытием: каждая следующая сдвинута влево на **8 px** (`margin-left = -8`), т.е. шаг 16 px.
- Контур каждой аватарки: **2 px** `#2F6BDB` (цвет «вырезает» аватарку из фона баннера).
- Заливка — шарики (радиальный градиент + блик):
  красный `#FF9A86 / #E5483A / #9E1F14`, зелёный `#8FE0A6 / #2FA85A / #16703A`, жёлтый `#FFE58F / #F2B91E / #B77A06`.
  В боевой версии — реальные аватарки топ-3 игроков (или шарики их цветов).
- Правее аватарок, отступ **7 px**: шеврон «›» — вес **800**, **20 px**, `#FFFFFF`, сдвинут на 2 px вверх (оптическая центровка).
- Блок не сжимается и не переносится.

## 5. Состояния и поведение

| Состояние | Что меняется |
|---|---|
| обычное | как описано выше |
| нажатие | сдвиг +2 px вниз, край 4→2 |
| 0 XP | меняется только подпись (см. п. 4.3). Цвета и вид те же |

Тап по баннеру — переход на **страницу** «Рейтинг» (не шторка). Страница: `Лидерборд страница.dc.html`.

Баннер **статичный**: никаких пульсаций, мерцаний и анимаций появления. Единственный синий объект на золотом экране — он привлекает внимание цветом, а не движением.

## 6. Положение на экране

Баннер стоит в пустой зоне между «Динамично как в UNO» и кнопкой «Начать игру», **по центру этой зоны**, а не прижатым к подписи.

Раскладка на макете 390×719:
- подпись «Динамично как в UNO»: top 145, высота ≈ 13 (низ ≈ 158);
- баннер: top **200**, низ 272;
- кнопка «Начать игру»: top **314** (меню поднято на 128 px — под ленту лобби внизу);
- зазоры: **подпись → баннер = 42**, **баннер → меню = 42** (равны).

Правило для Godot (экран может быть ниже/выше макета):
`баннер.top = подпись.bottom + (меню.top − подпись.bottom − 72) / 2`
Минимальный зазор с каждой стороны — **20 px**. Если места меньше — баннер остаётся 72 px высотой, а сжимаются зазоры (но не меньше 20).

На скриншоте реализации зазор сверху ≈ 14, снизу ≈ 110 — это и нужно исправить.
